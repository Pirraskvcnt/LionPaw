# 🦁 LionPaw — Petshop

Website de um petshop fictício, desenvolvido como parte das atividades acadêmicas do curso de Ciência da Computação, com o objetivo de aplicar conhecimentos em desenvolvimento web.

## 🐾 Sobre o Projeto

O **LionPaw** é um projeto de desenvolvimento Frontend que simula a presença digital de um petshop, explorando a criação de páginas web, organização de conteúdo e estilização de interfaces.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação e organização semântica das páginas.
- **CSS3** — Estilização, layouts e responsividade.
- **Git e GitHub** — Versionamento do projeto.

## 🚀 Como Visualizar

1. Clone o repositório:

   `git clone https://github.com/Pirraskvcnt/LionPaw.git`

2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## 📚 Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Estruturação semântica com HTML.
- Estilização de interfaces utilizando CSS.
- Organização de elementos e layouts.
- Fundamentos de design responsivo.
- Versionamento de código com Git e GitHub.
